
# 🧑‍💼 hh.PostgreS

Проект для сбора и анализа данных о вакансиях с сайта **HeadHunter (hh.ru)** с использованием **PostgreSQL**. Позволяет автоматически загружать информацию о выбранных компаниях и их вакансиях, сохранять её в базу данных и выполнять аналитические запросы через удобное консольное меню.

---

## 🚀 Возможности

- 🔍 Получение данных о работодателях и их вакансиях через официальное API HH.ru  
- 🗄️ Создание базы данных и таблиц в PostgreSQL  
- 💾 Сохранение данных с обработкой дубликатов  
- 📊 Анализ вакансий через консольное меню:  
  - список компаний с количеством вакансий  
  - список всех вакансий с зарплатами и ссылками  
  - средняя зарплата по всем вакансиям  
  - вакансии с зарплатой выше средней  
  - поиск вакансий по ключевому слову в названии  

---

## 🛠️ Технологии

- **Python** 3.9+
- **PostgreSQL** 13+
- **psycopg2-binary** — работа с базой данных  
- **requests** — взаимодействие с HH API  
- **python-dotenv** — управление переменными окружения  

---

## ⚙️ Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/morozoVik/hh.PostgreS.git
cd hh.PostgreS
```

### 2. Установить зависимости

```
pip install -r requirements.txt
```

### 3. Настроить базу данных

- Убедитесь, что PostgreSQL установлен и запущен.
- Создайте файл .env на основе .env.example и укажите параметры подключения к БД:

```
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=your_password_here
DB_HOST=localhost
DB_PORT=5432
```

### 4. Запустить парсер

```
python main.py
```

#### При первом запуске:

- будет создана база данных и таблицы
- загружены данные по компаниям и вакансиям
- запустится интерактивное меню для анализа

### 📈 Возможные доработки
- Веб-интерфейс (Flask/Django)
- Экспорт в Excel/CSV
- Фильтрация вакансий по региону и опыту
